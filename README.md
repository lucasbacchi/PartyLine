# PartyLine

This application is being developed as part of a Wentworth Institute of Technology Senior Project. Check back for updates.

## Project Overview

Churches, community centers, and non-profit venues frequently rent their facilities to external groups to generate revenue and serve their communities. To ensure the security of the building and to manage post-event turnover, organizations often require an on-duty employee to be available during each rental window, which poses a significant challenge as staffing shifts across rotating employee rosters. Currently, organizations must either provide employees’ personal cell numbers or use costly commercial VoIP systems (e.g., OpenPhone, Dialpad, RingCentral). We aim to address this through an implementation of a cloud communication platform with dynamic calendar scheduling and an API billed by actual usage rather than a per-user basis. Through this implementation, we can route calls and two-way SMS messages to the correct employee without revealing their personal phone number, reducing company expenses and maintaining employee privacy.
